QuickWash is a modern, responsive single-page web platform designed for an on-demand mobile car washing and detailing service. Built with semantic HTML5, mobile-first CSS3 (Flexbox & Grid), and vanilla ES6+ JavaScript, the application provides an interactive booking modal, service catalog cards, and smooth navigation.
